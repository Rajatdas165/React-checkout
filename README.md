# React Checkout (GitHub Pages)

A simple React checkout app with ₹ pricing, built with Create React App and pre-configured for GitHub Pages.

## Quick Start
```bash
npm install
npm start
```

## Deploy to GitHub Pages
1. Create a public repo named `react-checkout` under your account.
2. Ensure `package.json` "homepage" is `https://rajatdas165.github.io/react-checkout` (already set).
3. Run:
```bash
npm run deploy
```
Your app will be live at:
```
https://rajatdas165.github.io/react-checkout
```
